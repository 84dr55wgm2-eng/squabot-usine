Confidentialité

Privacy policy

Données utilisées / Data used

Uniquement l’autorisation Google donnée par le propriétaire des chaînes, pour publier sur ses propres chaînes YouTube et lire leurs statistiques. Only the Google authorization granted by the channel owner, to upload to and read analytics of their own YouTube channels.

Stockage / Storage

Le jeton d’accès est chiffré et conservé dans un dépôt privé du propriétaire. Rien n’est vendu, partagé ou transmis à un tiers. The token is encrypted and stored in the owner’s private repository. Nothing is sold or shared.

Personnes concernées / Who

Uniquement le propriétaire des chaînes. Aucune donnée sur les spectateurs. Only the channel owner; no viewer data is collected.

Services Google / Google services

Squabot utilise les services d’API YouTube. Squabot uses YouTube API Services — YouTube Terms of Service · Google Privacy Policy. L’utilisation des données reçues des API Google respecte la Google API Services User Data Policy, y compris les exigences d’utilisation limitée.

Retirer l’accès / Revoke access

myaccount.google.com/permissions → Squabot → Supprimer l’accès.
